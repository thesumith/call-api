      About this client

      A free Postman alternative in your browser

      Call API is a free online REST client for developers who want to test APIs without installing Postman or creating an account. Paste a URL, set headers or a JSON body, and send.

      What you can do

      • Send GET, POST, PUT, PATCH, DELETE, HEAD, and OPTIONS
      • Edit query params, headers, Bearer / Basic / API key auth
      • Pretty-print JSON, copy cURL, save and replay requests
      • Import Postman Collection v2.1 files

      Requests from this GitHub Pages site go directly from your browser, so APIs must allow CORS. For a local proxy that bypasses CORS, clone thesumith/call-api and run npm start.
