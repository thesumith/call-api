# Call API

Free Postman alternative online. Test REST APIs in the browser – no signup.

**Use it:** [https://thesumith.github.io/call-api/](https://thesumith.github.io/call-api/)

## Why use it

- Works in the browser as a free online API tester
- GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS
- Params, headers, JSON/text/form body, Bearer / Basic / API key
- Pretty JSON, response timing, cURL copy
- Import Postman Collection v2.1

GitHub Pages sends requests from the browser, so the API must allow CORS. For a local CORS proxy:

```bash
npm start
```

Then open [http://127.0.0.1:4040](http://127.0.0.1:4040).
